Important Concepts and Syntax:


• Input Handling
input()
int()

→ Used to accept marks from the user.

_________________________________________________________________________

• Exception Handling
try:
except ValueError:

→ Used to prevent crashes from invalid input.

_________________________________________________________________________

• Functions
def get_mark():

→ Encapsulates reusable input validation logic.

_________________________________________________________________________

• While Loop
while True:

→ Repeats until valid marks are entered.

_________________________________________________________________________

• Conditional Statements
if
else

→ Checks whether marks are within the valid range.

_________________________________________________________________________

• Lists
marks = [m1, m2, m3]

→ Stores all test marks.

_________________________________________________________________________

• Built-in Functions
min()
remove()
sum()

→ Used to remove the lowest mark and compute average.

_________________________________________________________________________

• Formatted Output
f"{average:.2f}"

→ Displays average with two decimal places.

Input validation
