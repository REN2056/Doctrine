Important Concepts and Syntax:


• Recursive Functions
def fn(n):

→ Defines Fibonacci recursively.

_________________________________________________________________________


• Base Cases
if n == 1
elif n == 2

→ Stops infinite recursion.

_________________________________________________________________________


• Recursive Call
fn(n-1)+fn(n-2)

→ Computes Fibonacci sequence.

_________________________________________________________________________


• Input Validation
if num > 0

→ Ensures valid input.
