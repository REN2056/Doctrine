Important Concepts and Syntax:


• User Defined Functions
def bin2Dec()
def oct2Hex()

→ Used for number conversion.

_________________________________________________________________________

• String Reversal
[::-1]

→ Processes digits from right to left.

_________________________________________________________________________

• For Loop
for dig in rev:

→ Traverses each digit.

_________________________________________________________________________

• Exponentiation
2**i
8**i

→ Computes place values.

_________________________________________________________________________

• While Loop
while dec != 0:

→ Converts decimal to hexadecimal.

_________________________________________________________________________

• ASCII Conversion
chr()
ord()

→ Converts values 10–15 into A–F.

_________________________________________________________________________

• String Joining
"".join()

→ Builds hexadecimal string.
